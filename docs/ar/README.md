# رايدان أوبنكود

**RaidanOpencode** - نظام تشغيل وكلاء OpenCode قابل للنقل، reproducible، ومتنوع المنصات.

## نظرة عامة

رايدان أوبنكود يجمع بين تثبيت OpenCode الحالي والإعدادات مع الأصول المعمارية من 37+ مستودع مرجعي لإنشاء نظام تشغيل لوكيل قابل للنقل. الهدف هو الإمكانية الإعادة (reproducibility) across Linux (Ubuntu 24.04)، Windows، و macOS دون cloning المستودعات كليا أو بيانات محددة للكمبيوتر.

## الفلسفة

- **قابلة للنقل**: يتم فصل الإعدادات إلى طبقات PORTABLE/MACHINE-SPECIFIC/SECRET/OPTIONAL/DEPRECATED
- **قابل للإعادة**: نصوص تثبيت كاملة لـ Linux (install.sh)، Windows (install.ps1, install.cmd)
- **متعددة المنصات**: نفس الهندسة تعمل على جميع أنظمة التشغيل الرئيسية
- **آمنة**: لا توجد أسرار مُرسلة إلى المستودع؛ جميع الأسرار خارجية عبر متغيرات البيئة

## الهندسة

النظام يوفر:

1. **منسق** - التخطيط للمهام وتنسيقmulti-agent
2. **سجل الوكلاء** - اكتشاف وتحميل المهارات
3. **محرّك المهام** - تطوير الاختبار الموجه (TDD)، دوائر التحقق
4. **مدير الجلسة** - حفظ السياق across sessions
5. **نظرية التشغيل** - Cloudflare Workers، execution المحلي، وغيرها
6. **هندسة الذاكرة** - ذاكرة موحدة مع Indexing HNSW AgentDB
7. **طبقة الرسائل** - MQTT، WebSocket، أو IPC للتواصل بين الوكلاء
8. **محرّك السياسات** - الأمان، الامتثال، والتحكم بالوصول
9. **نموذج الأحداث** - أنواع الأحداث والمعماات المعيارية
10. **نموذج الإعدادات** - إعدادات هرمية مع طبقات التقدّم

## التثبيت

### Linux

```bash
bash install.sh
```

### Windows

```powershell
# PowerShell
.\install.ps1

# موجه الأوامر
install.cmd
```
