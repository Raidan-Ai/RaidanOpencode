# نموذج التكوين متعدد المنصات

## نظرة عامة

يستخدم رايدان أوبنكود نموذج تكوين من 5 طبقات لفصل المخاوف وضمان إمكانية النقل عبر Linux, Windows, و macOS.

## الطبقات

### 1. PORTABLE (`~/.config/opencode/opencode.jsonc`)
التكوين الذي يعمل بالتساوي عبر جميع المنصات. يُرفع إلى المستودع.

**يشمل:**
- تعريفات الأدوات النظامية (apt, git, docker, etc.)
- إعدادات النماذج (مع `apiKey: "CONFIGURED"` - يستبدل عبر متغيرات البيئة وقت التشغيل)
- تعاريف MCP (temporal-docs, omniroute-http, omniroute-sse)
- تكوين A2A
- قائمة الإضافات (oh-my-opencode-slim)
- الإعدادات العامة والتفضيلات

**مثال:**
```json
"models": {
  "omniroute": {
    "apiKey": "CONFIGURED",  // يُحقن عبر متغيرات البيئة وقت التشغيل
    ...
  }
}
```

### 2. MACHINE-SPECIFIC (`~/.config/opencode/.machine-config.json`)
تكوين يختلف من مضيف لآخر. **لا يُرفع إلى المستودع**.

**يشمل:**
- ترتيبات المسارات (محددات المنصة)
-Paths الأدوات محددة بالمنصة
- إعدادات التخزين المحلي
- تفضيلات المضيف المحددة

**الاستخدام:**
```bash
# تحميل التكوين المحدد للمضيف إذا يوجد
if [ -f "$HOME/.config/opencode/.machine-config.json" ]; then
  # تطبيق الإعدادات الخاصة بالمضيف
fi
```

### 3. SECRET (`~/.config/opencode/.secrets.json` أو متغيرات البيئة)
أرقام المفاتيح، الرموز، والكشفانات. **لا تُرفع أبدًا إلى المستودع**.

**يشمل:**
- مفاتيح API لموفري LLM
- رموز الوصول لـ MCP/A2A
- سلاسل اتصال قواعد البيانات
- بيانات الاعتماد المصادقة

**الاستخدام - متغيرات البيئة:**
```bash
# Export secrets (never commit these!)
export OPENAI_API_KEY="sk-..."
export ANTHROPIC_API_KEY="..."
export OPENAI_API_BASE="https://..."
```

**الاستخدام - ملف الأسرار** (مغَـيَّر من المستودع):
```json
// ~/.config/opencode/.secrets.json - gitignored
{
  "apiKey": "sk-...",
  "accessToken": "oma_live_j_..."
}
```

### 4. OPTIONAL (أعلام الميزات في opencode.jsonc)
الميزات والتكاملات التي يمكن تفعيلها/إلغاء تفعيلها دون تغيير الكود.

**يشمل:**
- MCP servers مع `enabled: true/false`
- A2A مع `enabled: true/false`
- أعلام الميزات للتجريبي

**مثال:**
```json
"mcpServers": {
  "omniroute-http": {
    "type": "remote",
    "url": "http://...",
    "enabled": false  // Disable if not needed
  },
  "omniroute-sse": {
    "type": "remote", 
    "url": "http://...",
    "enabled": true   // Enable by default
  }
}
```

### 5. DEPRECATED
الميزات القديمة/المُزالَة المحفوظة للتوافق الرجعي.

**يشمل:**
- خيارات التكوين القديمة
- MCP servers أو النماذج المُزالَة
- أعلام الميزات废弃

**مسار الهجرة:**
- وثق ال Deprecation في AGENTS.md
- قدم دليل الهجر
- أزله بعد النسخة الرئيسية التالية

## تسلسل أولوية التكوين

عند تحميل التكوين، ينطبق التسلسل التالي (الأخير يفوز):

1. **DEFAULT** - الإعدادات الافتراضية المدمجة (أولوية أدنى)
2. **PORTABLE** - `opencode.jsonc` (مُرفَق في المستودع)
3. **MACHINE-SPECIFIC** - `.machine-config.json` (لكل مضيف)
4. **SECRET** - متغيرات البيئة أو `.secrets.json` (يُلغي كل ما فوق)
5. **RUNTIME FLAGS** - أعلام سطر comando (أعلى أولوية)

## سير عمل التثبيت

### Linux (install.sh)
```bash
# 1. Apply portable configuration
cp opencode.jsonc "$HOME/.config/opencode/opencode.jsonc"

# 2. Apply machine-specific config if it exists
if [ -f "./machine-config.json" ]; then
  cp ./machine-config.json "$HOME/.config/opencode/.machine-config.json"
fi

# 3. Export secrets from environment or .secrets file
if [ -f "$HOME/.config/opencode/.secrets.json" ]; then
  export $(grep -v '^#' "$HOME/.config/opencode/.secrets.json" | xargs)
elif [ -n "$OPENAI_API_KEY" ]; then
  # Use existing env var
  :
fi

# 4. Initialize skills and commands
# (skills/ and commands/ directories are portable)
```

### Windows (install.ps1 / install.cmd)
```powershell
# 1. Apply portable configuration
Copy-Item .\opencode.jsonc "$env:HOMEPATH\.config\opencode\opencode.jsonc"

# 2. Apply machine-specific config if it exists
if (Test-Path .\machine-config.json) {
  Copy-Item .\machine-config.json "$env:HOMEPATH\.config\opencode\.machine-config.json"
}

# 3. Load secrets
if (Test-Path "$env:HOMEPATH\.config\opencode\.secrets.json") {
  $secrets = Get-Content "$env:HOMEPATH\.config\opencode\.secrets.json" | ConvertFrom-Json
  # Apply secrets to environment
}
```

## إدارة الأسرار

### لا تُرفع أبدًا:
- مفاتيح API (`apiKey`, `OPENAI_API_KEY`, إلخ)
- رموز الوصول (`access_token`, `oma_live_...`)
- بيانات اعتماد قواعد البيانات
- أي قيم سرية

### دومًا استخدم:
- متغيرات البيئة للتشغيل المحلي
- ملف `.secrets.json` (gitignored) للتطوير المحلي
- أدوات إدارة الأسرار (HashiCorp Vault, AWS Secrets Manager, إلخ) للإنتاج

### هجرة من الأسرار المضمَنة:
1. إزالة الأسرار المضمنة من `opencode.jsonc`
2. استبدالها بعنوان `"CONFIGURED"` الاحتياطي
3. وثق أن الأسرار يجب توفيرها عبر البيئة أو `.secrets.json`
4. تحديث نصوص التثبيت لتحميل الأسرار من مصادر آمنة
5. أضف `.secrets.json` إلى `.gitignore`

