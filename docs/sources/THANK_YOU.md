# THANK YOU

RaidanOpencode exists because of the open-source ecosystem.

To the **developers and maintainers** whose work we studied, measured, and learned from — thank you. Twenty-one repositories were analyzed in depth for this project; every design decision here traces back to something the community figured out first:

- [darrenhinde/OpenAgentsControl](https://github.com/darrenhinde/OpenAgentsControl) — context discipline and approval gates
- [ZaxbyHub/opencode-swarm](https://github.com/ZaxbyHub/opencode-swarm) — gated pipelines and guardrail engineering
- [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) — proving that less code is a feature
- [asheshgoplani/agent-deck](https://github.com/asheshgoplani/agent-deck) — conductor patterns and worktree lifecycle
- [5dive-ai/5dive](https://github.com/5dive-ai/5dive) — security-first agent isolation thinking
- [Untrivial-ai/agent-orchestrator](https://github.com/Untrivial-ai/agent-orchestrator) · [bytedance/deer-flow](https://github.com/bytedance/deer-flow) · [ruvnet/ruflo](https://github.com/ruvnet/ruflo) · [ruvnet/agentic-flow](https://github.com/ruvnet/agentic-flow) — orchestration at scale
